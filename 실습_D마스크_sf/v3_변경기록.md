# v2 → v3 변경 기록

범위: 사용자 지시에 따라 4·6절만 개정함. 1·2·3·5절은 v2와 동일(스크립트 대조). 표지 줄 판 표시만 v2→v3. 분량: 공백 제외 5,993자 → 6,000자(상한 준수, 4·6절 안에서 기존 문장 압축). 원문 차이는 v2_v3.diff.
