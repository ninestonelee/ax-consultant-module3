## 인터뷰에서 드러난 쟁점

1. 생산량은 그대로인데 성형기 가동시간이 280h→320h(+14.3%)로 늘어 원단위도 0.028→0.032로 올라감. 원인은 기록이 없어 확인되지 않음(C14).
2. 불량률이 월 0.1%p씩 오르지만 설비별·유형별로 나뉘어 있지 않음. 비전 AI 학습용 불량 이미지는 0장(C15).
3. 불량 계수 기준(최초 불량 1회 계수)은 구두 설명뿐이라 문서화된 기준이 필요함(C04).
4. 전력 경계 불일치: 분자는 성형기 3대만 포함(실링기 4대 제외)하고 분모는 완제품 생산 수임. 계획서에는 '성형기 추정 원단위'로만 표기해야 함.
5. 전력계가 없어 전력 목표를 정할 수 없음. 계측 설치가 구축 범위의 선행 조건임(C06).
6. 목표치·예산·공급기업·인원·현재 수준·안전 자료가 모두 미정임(C08~C13).
