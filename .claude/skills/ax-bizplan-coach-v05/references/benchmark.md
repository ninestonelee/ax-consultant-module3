# 비교 실험

1. 작성 전에 자료 허용목록과 비교 기준, 누락·부분·도달의 정의, 적용 제외 행을 고정한다. 채점 힌트·선정본·이전 원고는 작성자에게 주지 않는다. 다른 작업의 메시지·상태 목록이 정답을 노출할 수 있으므로 작성자는 이를 조회하지 않는다.
2. 두 모델 또는 두 사람이 각각 같은 익명 원고를 같은 과업 기준으로 평가한다. 기존 작성 순서·점수와 상대 평가표를 공유하지 않는다. 독립된 인간 심사가 없는 경우 모델 검토라고 기록한다. 두 평가표 고정 후 원본의 실제 페이지와 1:1 대조하고 의견 차이와 보수적 판정을 함께 보고한다.
3. 일부 입력이 기준 사례에서 유래했으면 회귀 실험이라고 표시한다. 훈련·개발자가 보지 않은 업종/설비 사례와 데이터를 별도 예약한다. 예약 시 입력·정답 지문과 평가 시점을 기록하고 실제 사용 전에는 정답을 스킬 폴더에 두지 않는다. 원장 있는 기업, 데이터 이력 없는 기업, 목표가 상충하는 기업에서 발견·오탐·누락을 따로 센다. 동일 사례 점수를 합격선이나 업종 전반 성능으로 확장하지 않는다.
