# 원장 항목과 기간별 지표 명칭

자료 A의 원장 열과 자료 B에서 정의한 지표가 비슷하거나, 연도별 집계 기준이 달라질 수 있으면 다음 순서로 원고를 검토한다.

1. 원장 헤더의 명칭·단위와 기간별 값을 원문대로 옮긴다. 회사가 더 좁은 용어를 사용한 기록이 있으면 그 명칭, 적용 기간·품목·채널, 포함/제외·중복 처리, 원문 위치, 관측/목표를 해당 기간에만 연결한다. 같은 숫자가 두 자료에 나왔다는 사실만으로 정의를 다른 기간에 소급하지 않는다.
2. 여러 연도를 가로지르는 표를 쓸 때 공통으로 입증된 명칭으로 헤더를 정하거나 기간·원장 명칭·건수·인정 정의·산식·구분을 행으로 분리한다. 정의가 달라도 원자료로 각 기간의 단순 전환 비율은 검산할 수 있다. 같은 정의의 추세 비교를 하려면 과거 원장에 같은 키와 기간창을 적용할 수 있는지 먼저 확인한다.
3. 조건을 붙인 용어를 실제로 쓴 곳은 원고·요약표·성과지표·계산표·근거 대장·Word까지 확인한다. 과거 원장, 규칙이 적용되는 기준기, 미래 목표를 나란히 읽는다. 분모·분자가 함께 늘어 비율이 같을 때는 ‘건수 증가’와 ‘전환율 유지’를 따로 기재한다.
4. 좁아진 지표명이 있으면 아래 검산기를 사용한다. 제출 원고에 싣는 각 기간의 값과 근거를 입력한다. 원장값(raw)은 CSV의 실제 행·열에서 읽고 정의값(defined)·목표(target)는 정의 원문의 기간·명칭·값을 짧은 인용 범위에서 확인한다. raw의 표기 변경은 정의 근거를 가진 행으로 풀어 쓴다. 원본 데이터가 PDF 등 다른 형식이면 페이지·표를 직접 대조하고 동일한 기간별 검토를 수작업으로 기록할 수 있다. 이름과 값·기간을 한 줄로 뽑을 수 없는 경우 직접 판독한 범위를 남긴다.

UTF-8 CSV 대장의 헤더는 아래와 같다. file은 실행 폴더 기준 상대경로다. raw에서는 period_column, value_column에 실제 원장 열명을 넣는다. name은 단위 접미사 앞의 원장명으로 쓰거나 전체 열명을 유지한다. defined·target의 quote는 한 주장에 해당하는 정확한 원문이고 rule은 집계 조건의 원문 인용이다. 지표 단위와 의미는 검토자가 원자료에서 함께 확인한다. 명칭 비교 시 한국어 띄어쓰기 차이를 허용한다.

```
period,name,value,kind,file,period_column,value_column,quote,rule
```

```sh
python3 scripts/check_metric_scope.py /work/회차 /work/회차/지표명대장.csv
```

예를 들어 기존 원장에서 ‘접수’로 집계한 두 기간에 최근 적용한 중복 제거 규칙이 없으면 과거는 ‘접수’로 둔다. 최근 기간에만 규칙을 적용한 ‘유효 접수’의 관측치와 다음 기간 목표를 각각 별도 행으로 둔다. 출처가 있는 자기점검과 본문 전체의 표기 검토를 의도한 도구로, 결과 보고 시 원고·Word 수기 대조 여부도 표시한다.
