# 제조AI 제출 준비형

교육용 6절과 구별해, 기업이 공급사와 협의하고 실제 신청서로 옮기는 데 쓸 **장별 작성본**, **양식 대조표**, **미확보 증빙 대장**을 함께 만든다. 기술·비용·검수 항목에는 [engineering.md](engineering.md)를 적용한다.

## 신청 회차와 양식 고정

착수 기록에 사업명·연도·회차·유형, 공고 번호·게시/정정일, 공식 발행처, 신청 양식 버전, 각 원문 파일명/URL·쪽·표 번호를 적는다. 공고, 빈 신청 양식, 교육 지침, 인터뷰, 공급사 제안은 서로 다른 자료로 등록한다. 공고 해석은 조항과 해석자를 함께 적는다. 기존 선정작은 비교 자료이며 신청 회차의 공식 요건을 정하는 자료가 아니다.

- 정정공고와 빈 양식이 있으면 양식의 장·표·서명·첨부 순서를 따르고, 아래 과업을 실제 셀로 옮긴다. 번호·순서가 다르면 실제 양식을 우선한다. 한글 양식이나 스캔 PDF는 페이지 이미지로 제목·빈 표·날인란까지 확인한다.
- 빈 양식이 없거나 사업 회차가 특정되지 않으면 아래 10장으로 작성하되 표지에 **잠정 작업본 · 공식 양식 미대조**를 표시한다. 참고자료에 들어 있는 과거 지원 상한·지급 비율·필수비목·배점은 현 회차 기준으로 단정하지 않는다. 수치 예시는 교육 가정으로만 쓴다.
- 각 조항은 적용·비적용(근거)·미확인으로 판정한다. 가점·별도 수행유형·참고자료는 조건부로 둔다. 실제 가점 증빙이나 당사자 의사가 확인되어야 신청 대상으로 표시한다. 회차·서식이 바뀌면 인용 조항, 금액·비율, 일정, 첨부 의무를 다시 대조한다.

## 장별 과업

본문의 각 장에는 현재 입력에서 근거가 있는 내용, 제안하는 실행 방법, 남은 결정과 담당자를 적는다. 각 표와 첨부는 form-map.csv에 기록한다. 준비도는 **본문의 구체성**과 **증빙 수신 상태** 두 열로 표시한다. 빈 서식이나 상세한 제안이 생겨도 외부 증빙 상태는 변하지 않는다.

| 잠정 장 | 독자가 해야 하는 판단 | 작성할 결과와 인수 기준 |
|---|---|---|
| 1. 구축 개요 | 왜 이 공정이며 무엇이 얼마나 바뀌는가? | 기업·구축 이력, 현행 수준→목표 수준, 현행 및 개선 공정·가치사슬, 업무·자동화·제어의 포함/제외, 사업 KPI와 측정 경계, 보유/신규/개선 장비. 실사 사진이 없으면 소재·주요 지점·촬영 책임자의 요청 행을 둔다. |
| 2. 시스템 구성·구축 명세 | 장비·데이터·모델·사용자 기능을 제작·시험할 수 있는가? | HW 사양과 위치별 장비 대장, 물리·논리 구성도, 화면·기능·신규/기존 구분, 데이터 사전·연계, 모델별 범위·성능/설비 기준. 위치 실물이 없을 때는 공정 개념도만 작성. 표준연계 가점·별도 데이터 수집 유형은 적용 근거로 분기. |
| 3. 추진 일정·산출물 | 조달·설치·데이터 수집·시험이 납기 안에 가능한가? | 선행 작업, 담당, 가용 인력, 목표 기간, 납품물과 승인 담당. 요구사항→구축 기능→단위/통합/사용자 시험 연결. 수집이나 자재 납기 지연 시 영향받는 단계·보류 범위를 제시한다. |
| 4. 사업비 내역 | 같은 재원으로 계획한 기능을 납품할 수 있는가? | 조달 재원과 지출 비목을 분리하고 품목별 수량·단가·견적번호·VAT 처리, 개발 공수나 기능점수 근거, 인건비·현물 산출 근거를 기재한다. 합계를 대사하고 미확정 지출은 잔여 재원과 분리한다. |
| 5. 추진조직·업무분장 | 누가 언제 의사결정·개발·검수·정산을 맡는가? | 도입/공급별 결정권·담당/대리·기간·월별 가용공수·산출물·승인자. 후보사의 등록·유사 실적·기명 인력·확약을 사건별로 확인한다. 한 사람이 겸직하면 역할별 시간이 가용시간과 정산 상한을 초과하지 않는지 확인한다. |
| 6. 운영·사용자 훈련·유지보수 | 장애나 중도포기 때 누구에게 무엇을 인계하는가? | 교대별 조작 교육·실습 수료 판단, 장비/소프트웨어별 보증·유무상 범위·응답과 복구, 백업·복원·연락망·운영권 이관. 도입/공급/공동 귀책별 기성·지급/반환·소유/사용권·데이터 인계를 협약 확인 대상으로 둔다. |
| 7. 사업교육 수료 계획 | 해당 회차에서 누가 어떤 과정을 이수해야 하는가? | 제도 교육과 6장 현장 조작교육을 구분한다. 도입·공급사별 공고 근거, 과정·대상·시기·책임자·확인 자료·수료 상태를 적는다. 출석 자료 없이 수료를 확정하지 않는다. |
| 8. 고용유지·창출 | 인력 수에 어떤 변화가 있으며 근거가 있는가? | 기준일의 양사 현원, 직무전환·유지·채용 의사결정, 연도별 계획·산출 근거, 증빙 담당. 신규채용 미확정과 확인된 무계획(0명)을 구별한다. 현 인원에서 미래 고용을 자동 산출하지 않는다. |
| 9. 산업안전·보안 | 설치·운영 중의 위험과 데이터 접근을 누가 관리하는가? | 공정별 설치·점검·운영 위험, 안전담당·작업 승인·작업 보류/재개·사고 보고, 필요한 현장 위험성평가를 명시한다. 별도 보안표에 역할권한, 원격 접속 승인·회수, 보관·복구, 통제별 증빙/예외를 기록한다. |
| 10. 효과 및 확산 | 어디까지가 효과 가정이고 무엇을 실측해야 하나? | KPI별 기준·목표·근거·비교기간, 시나리오별 회피비용·단가·중복·운영비, 단기 운영과 다음 적용처·재검수 조건. 다른 제품·공장에는 실측과 결정을 별도로 요청한다. |

부속서는 **사업계획의 최종합의**와 **미래의 구축 완료 인수**를 구분한다. 최종합의 준비표에 문서 버전·협의 일시·미해결 쟁점·양측 권한자·서명 상태를 넣는다. 회의·서명이 없으면 안건과 승인 경로만 작성한다. 공식 양식이 들어오면 빈 서명란과 붙임 위치를 유지한다. 사진·도면·견적·협약·실적·인증은 받은 파일만 편철한다. 필수/선택/참고 성격을 각 첨부에 기입한다. 당사자 서명·납품·고용·실적을 대신 생성하지 않는다.

## 증빙 수집과 개정

1. [form-map.csv](../assets/submission/form-map.csv)에 장보다 작은 표·별첨을 한 행씩 만든다. 같은 양식 칸이 여러 자료를 요구하면 해당 자료 ID를 각각 연결한다. 공식 양식이 없을 때의 내부 목차와 실제 공고상 필수 여부를 구분한다.
2. [evidence-requests.csv](../assets/submission/evidence-requests.csv)에 실제 결정을 막는 항목을 모두 남긴다. 담당자(대표·현장·품질·인사·공급·안전 등), 정확한 요청 파일, 용도, 기준일/단위, 기한 또는 기한을 정할 사건, 검토자, 출처 ID를 기입한다. 담당자별로 한 번에 요청하되 수신과 보완은 여러 회차로 기록한다. 출처 간 충돌은 두 출처와 선택 권한자를 모두 표시한다.
3. 상태는 미요청→요청→수신·검토중→확인 또는 보완요청으로 기록한다. 계획 단계의 미래 실측/검수 기록은 ‘구축 후 수집’으로 따로 표시한다. 합성 인터뷰·원장은 자료 종류가 **합성**이므로 실물 증빙 확인으로 올리지 않는다.
4. 증거를 받으면 바뀐 행·근거와 영향받는 본문, 산식, 비용 및 시험을 갱신한다. 다수 결손을 본문에 반복할 필요는 없으나 요청 대장에는 빠짐없이 남긴다.
5. 결과 표지에 양식 매핑 상태, 작성 가능한 장, 제출 전 미결정/증빙 미도착, 구축 후 확인, 조건부 별첨을 구분한다. 필수 적용 여부·금액 충돌·견적·서명이 미확정이면 완성된 Word와 별개로 제출 준비 판정을 보류한다.
