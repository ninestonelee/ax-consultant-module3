# 수치·주장 원장

문서에 반복해서 나오는 KPI, 목표, 장비 수, 소요액은 하나의 사전에서 가져온다. 각 ID에 value, status, source, scope, period, owner를 둔다. source에는 파일명과 행·표·문단 또는 실측 식별자와 산식을 넣는다. 합성 입력과 실측, 후보 목표와 승인 목표는 같은 상태가 아니다. 불확정 금액에는 ‘견적 미수령’을 쓴다. 사이클이 다른 두 목표가 상충하면 각 출처·단위·기간·설비범위를 확인하고 승인 전에는 status를 ‘충돌’로 둔다.

예: {"output.total":{"value":"24개","status":"합성 원장 계산","source":"예시.csv 데이터행 1~2, 10+14","scope":"대상 라인 총생산/개","period":"실습월","owner":"품질 담당"}}. 원고에는 {{output.total}}을 인용한다. `python3 SKILL/scripts/materialize.py template.md values.json final.md`가 모든 인용을 함께 갱신하고 맨 뒤에 역추적 표를 붙인다. 표가 긴 경우 교육형 본문에는 --no-appendix 옵션을 쓰되 별도 근거 원장을 함께 제공한다. 문단에서 반복되는 값을 직접 입력한 경우에도 발행 전 원장과 대조한다.

check_case.py에서 계산한 값은 반올림 자리·분모·증빙 상태를 유지해 사전에 옮긴다. 적용 회차 또는 실측이 달라지면 수치 원장·연관 파생식·차트·예산·시험 항목을 다시 계산한 뒤 전체 원고를 렌더링한다. 각 파생값의 계산식도 출처에 남기고, 미확정 조건은 사용자/현장 승인 전에는 최종 값으로 승격하지 않는다.
