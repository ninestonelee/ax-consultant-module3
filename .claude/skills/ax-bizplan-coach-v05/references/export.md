# Word 출력과 양식 확인

Python 3.9 이상과 python-docx가 필요하다. 최초 한 번 스킬 폴더의 requirements.txt로 현재 사용 중인 Python 환경을 준비한다. 파일 경로는 사용자가 설치한 스킬과 실습 폴더로 바꾼다. 현재 작업 디렉터리는 자유다.

```sh
python -m pip install -r "/path/to/ax-bizplan-coach-v05/requirements.txt"
python "/path/to/ax-bizplan-coach-v05/scripts/build_docx.py" "/work/final.md" "/work/계획서.docx" --title "제조AI 사업계획서" --company "도입기업명" --version v3 --date 2026-11-19 --mode submission
```

날짜는 해당 작성일로 지정한다. 독립 실행 환경에서는 Noto Sans KR을 설치하거나 Word/렌더러에 한글 대체 글꼴을 구성한다. 교육형은 `--mode education`이다. 제출 준비형의 기본 출력은 ‘공고 원본 양식 미적용’ 표시가 있는 A4 초안이다. 현재 회차 공식 서식을 받지 않았으면 승인 여부는 미확인으로 둔다.

본문에는 Markdown 제목(#~######) 또는 ■·□ 제목, 줄글, 한 줄 항목, 단순 표를 쓴다. 표 범위는 '|'로 시작하는 연속 줄이고 본문 안 세로줄은 '\|'로 표기한다. 표 안 줄바꿈은 <br>이다. `![그림의 내용과 자료 근거](figures/line.png)`는 원고 기준 상대 경로에 있는 그림과 캡션을 넣는다. 실사 도면이 없을 때에는 캡션을 ‘개념도’로 표기한다. 원격 그림을 자동으로 받아오지 않는다. 페이지 정보는 일반 출력의 바닥글에, 원본 양식을 적용했을 때는 기존 바닥글을 유지하고 버전·일자를 문서 속성에 남긴다.

## 제공받은 DOCX 양식에 작성하기

1. 공고에서 받은 파일 원본을 보관하고 작업용 사본을 만든다. 작성 위치마다 `{{SUMMARY}}` 같은 영문 ID를 독립된 한 문단에 적는다. 표 셀 안도 가능하며 기존 문단·표·사진·서명란은 그대로 둔다. 원본의 빈칸 하나마다 어떤 절을 넣을지 판단한 사람이 승인한다. 편집 권한 또는 필수 부속서·날인란을 임의로 바꾸지 않는다.
2. 작업 사본의 SHA-256을 산출하고, 해당 공고·양식 식별자와 원본 파일의 해시는 별도의 공고대장에 보관한다. 매핑 JSON은 작업 사본의 해시를 사용한다. 각 원고 절 제목은 앞의 Markdown 기호를 제외하고 정확히 일치시킨다.

```json
{
  "template_sha256": "자리표시자를_넣은_DOCX의_SHA256",
  "fields": {
    "{{SUMMARY}}": "1. 구축 개요",
    "{{COST}}": "2. 사업비"
  }
}
```

3. 기본 출력 명령에 `--template "/work/서식_작업본.docx" --field-map "/work/필드매핑.json"`을 추가한다. 절 전체(해당 제목·하위 제목·표·그림 포함)를 자리표시자 문단에 삽입한다. `"$body"` 한 항목으로 원고 전체를 넣을 수도 있다. 양식 해시·매핑 필드·원문 범위가 다르거나 필드가 중복되면 출력을 중단한다. 매핑되지 않은 앞표지 제목도 별도 절로 지정하거나 원고에서 제거한다. HWP·PDF, 기존 콘텐츠 컨트롤, 텍스트 상자·머리글 내부의 필드는 자동 기입 대상이 아니다. 해당 서식으로 전사하거나 공식 양식에 맞춘 DOCX 사본을 제공받는다.
4. 실제 사용한 양식 ID·파일 해시·매핑본·작성 상태를 실행 결과에 저장한다. 글자수는 교육 본문의 예산을 적용하되, 제출형에는 목차·필드별 공식 분량 기준을 우선한다.

## 출력 검수

- 본문 절·표·그림·캡션과 예상 항목 수를 원고와 맞춘다. 목표·단위·비용·증빙 표시와 미서명 양식의 상태도 재확인한다.
- 문서를 열거나 PDF로 렌더해 한글 글꼴, 장별 제목, 쪽번호, 긴 표의 반복 머리행·행분할·잘림을 살핀다. 페이지 크기보다 긴 단일 표 행은 줄이거나 여러 행으로 나눈다.
- 공식 양식은 빈 양식과 채운 양식 모두 렌더해 기입 위치·크기와 그림으로만 남은 합의서·날인란까지 확인한다. 스캔 면의 본문이 문자 추출 결과에 없더라도 육안 확인 대상으로 기록한다. 파일과 문서 구조만 검사한 경우 결과에 시각 검증 미수행을 밝힌다.
