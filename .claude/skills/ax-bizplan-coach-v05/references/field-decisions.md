# 현장 조건에 따라 달라지는 15가지 결정

제출 준비형에서 각 항목은 **자료 ID·행 → 비교안 → 선택 또는 보류 이유 → 승인에 필요한 증빙 → 영향받는 본문·붙임**으로 기록한다. 협의에 쓸 설계는 현재 자료로 제안할 수 있다. 발주·지급·이수·기명 동의·안전조치 이행·서명은 실제 근거가 있는 범위까지 각각 판정한다. 아래 값은 계산 방법을 설명하는 독립적인 가정이다. 사례 수치나 공식 기준으로 가져가지 않는다.

## 1~5. 공정 인계, 자산, 설치, 배포, 데이터

|장에 넣을 판단|입력이 있는 경우|미수령·충돌 시 남길 선택지와 발주/검수 조건|
|---|---|---|
|① 물류·정보 인계|공급처→입고→대상 공정→검사·격리→출하→고객의 실물 흐름을 그리고, 각 경계마다 넘기는 사람/받는 사람·LOT/전표·시간·현재 작업·개선 후 작업을 쌍으로 적는다. 재작업은 분기와 복귀 지점을 그린다.|전자 스캔/종이 전표 대안을 같은 인계점에서 비교한다. 사진·현장 배치·대장 행으로 확인된 점은 실선, 위치 미확인은 ‘가배치’라고 쓴다. 반장이 동선·충돌·수동 대체를 승인할 때 좌표·장비 위치를 고정한다.|
|② 보유/신규 HW·SW|품목 ID별 보유 수량, 상태·잔여 지원, 호환 시험, 재사용·개선·신규·제외, 대응 기능, 비교용 금액, 확정 견적 ID를 한 표로 만든다.|기존 단말이 권한 분리·지원 버전·처리 성능 시험을 통과하면 라이선스·설치만 반영한다. 실패하면 대체 단말 안을 비교한다. 보유 원가·이미 포함된 라이선스·공유 서버의 이중 계상을 제거한다.|
|③ HW 설치 및 수량|계통도에 설비 태그·전원반/분기·신호점·게이트웨이/단말의 위치와 수량을 표시한다. 도면 번호·개정·회로 경계·안전 승인·설치 가능 시간·공사 포함 여부를 수량표와 대응한다.|공유회로 전체 계측과 부하별 분계측을 비교한다. 공통 부하가 섞이면 개별 설비 실측 판단을 보류한다. 측정점 수 S, 장치당 실제 사용가능 채널 C면 동일 제약군당 최소 장치 수는 올림(S/C)이다. 거리·격리·분전반이 다르면 그룹별로 올려 합친다. 예비율은 요청 근거가 있을 때 별도 표시한다.|
|④ SW·망 구성|‘계기/설비 → 수집 노드 → 중계구간 → 저장/서비스 → 현장·사무 화면’에 배포 위치·방향·승인 프로토콜·작동 주체·장애 시 저장/재전송을 직접 표시한다. 기능을 어느 단말에서 누가 쓰는지 적는다.|기존 서버에 자원·백업·복구·지원정책 증거가 있으면 수용 후보, 부족하면 전용 서버나 허용된 외부 서비스를 비용·지연·운영인력으로 비교한다. 현장 접속 허용·계정 책임·단절 재생 시험 확인 후 배포·발주한다.|
|⑤ 보유/신규 관측|공정별 ‘태그·의미/단위·기록주기·검사주기·LOT/시각 키·보존기간·보유량·출처·신규 수집·시험’을 쓴다. 샘플 간격과 일·LOT별 집계 주기를 별도 열로 둔다.|예를 들어 1초 2태그를 8시간 수집하면 결측 전 57,600값이다. 1분 요약은 960값으로 짧은 이상 이벤트 보존 여부가 달라진다. 신호 변동·장비 능력·저장량·검사 지침으로 선택한다. 명판·태그목록·시각 동기·검사자 확인 전 단위/주기는 제안값이다.|

**문서에 실을 도식.** 물류 도식은 ‘투입 자재 → 공정 A → 검사 → 인계처’와 ‘검사 불합격 → 격리·재작업 → 재검’ 두 행을 사용한다. 정보 행은 ‘입고 전표 → LOT 시작/종료 → 검사 사건 → 출하 전표’로 놓고 열을 맞춘다. 장비/망은 ‘반·채널·수집 노드 │ 망 경계 │ 저장·화면’을 별도 도식으로 배치한다. 도면이 있으면 위치·근거와 범례를 넣고 개념도는 캡션에 표시한다. 예를 들어 격리된 두 반에 각 3점, 4채널 장치라면 두 반에 각 1대이다. 장치에 승인된 입력 형태가 없으면 산술 최소수량만 남고 발주수량은 보류된다. Markdown·Word 모두에서 보이도록 짧은 표/문단 또는 내장된 이미지로 구현한다.

## 6~7. 세부 사업비와 실제 인력

|결정|산식·조건별 예|본문과 붙임에서 확인할 것|
|---|---|---|
|⑥ 사업비·견적|같은 사양의 A안(재사용 설치비), B안(신규 수량×단가+설치비)을 같은 VAT·기간·납품 범위로 비교한다. 계산 연습으로 장치 2대×35만원+설치 12만원=공급가 82만원이다. 세율 10% 가정이면 90.2만원이고, 실제 세액 적격성은 회차 기준을 따른다. 별개 개발 6인일×40만원=240만원, 현물 300만원/월×2개월×20%=120만원 예시도 내역당 한 번만 계상한다.|재원 합계와 지출 소계·기확정·조건부·미배정 잔액을 분리한다. 견적 만료, 옵션품·운송/시운전 포함, 계약 전 비교 조건을 쓴다. 제안 단가나 일부 견적을 전체 확정 사업비로 집계하지 않는다. 복수 견적은 동일 범위로 환산하고 선택 사유와 보류 행을 남긴다.|
|⑦ 양사 조직과 가용시간|월·역할·도입/공급·기명 상태·대리, 업무별 공수, 본업 차감 후 가용공수·산출물·승인자를 연결한다. 예를 들어 월 가용 16시간에 교육 8시간+시험 10시간이면 2시간 부족하다. 승인된 대리배치 또는 비선행 2시간 순연의 두 안을 일정에 반영한다.|실명·서명된 배정표가 오면 그 달·역할만 확인한다. 동명이인/겸직·출장·교대 겹침을 점검한다. 사내 승인자, 공급사 수행자, 정산 검토자의 역할과 시간·대리를 분리해 구매·기성·인수 권한을 표시한다.|

## 8. 현업을 유지할 수 있는 사용자 훈련

**강사 제안안**에는 과정마다 수행과제, 교육 담당 강사·대리 강사 역할, 수강 직무·인원, 1회 순수 훈련시간, 실습 좌석·교대별 이탈 가능 인원, 분반 수·강사 점유시간, 적용 시점, 성취 판정·보강 시간을 쓴다. 사용자 수료와 강사의 진행 이력을 따로 남긴다. 강사 이름·교대 확약은 근거 수신 후 기록한다. 현장 인원이 주어졌으면 그 인원으로 계산한다. 생산을 유지할 최소 잔류 인원·좌석이 없으면 복수 전제의 계산 가능한 **잠정 편성**을 제시하고 근무표·승인자를 요청한다.

각 교대/직무에서 동시 수강 가능 인원은 ‘출근한 해당 인력−상시 잔류 인력−당일 결원’과 ‘강사가 동시에 지도 가능한 실습석’ 중 작은 값이다. 역할별 필수 배치도 만족해야 한다. 총원이 같아도 교대별 숫자를 모르면 한 교대에 합산하지 않는다. 동시 가능 인원이 0 이하면 교대 내 개설을 보류하고 대체근무 또는 비가동 시간과 임금·승인을 확인한다. 분반 수는 대상 인원/동시 가능 인원을 올림한다. 강사 점유시간=회차수×회당 시간+준비·이동·보강, 수강자 인시=실제 수강인원×회당 시간이다. 서로 다른 역할을 겸하면 시간표에서 겹치는 구간을 먼저 해소한다.

아래는 **한 교대 5명·잔류 3명·실습석 2석, 품질담당 2명 동시 이탈 가능**을 전제로 한 강사 편성 예이다. 실제 교대 시각이 없으므로 운영 중 겹치지 않는 시간창으로 표시한다.

|과정/강사(후보)|대상·실습/현장 확인|회당 시간·분반|강사 시간/수강 인시|시점·수료 판단|
|---|---|---|---|---|
|조작·재전송 / 공급사 현장강사|현장 5명, 2·2·1명 순차. 시험 LOT 입력·오프라인 재전송|45분×3회|2시간 15분/3시간 45분|시운전 첫날 창 A~C. 중복 없이 복구 후 원장합 일치|
|경보·격리 / 품질강사|현장 5명, 2·2·1명 순차. 확인→격리→해제 요청|60분×3회|3시간/5시간|다음 근무일 창 A~C. 모의 경보에서 정해진 작업을 독립 재현|
|승인·정정 / 품질책임 강사|품질 2명. 정정 전후 비교·승인로그 출력|90분×1회|1시간 30분/3시간|현장반 교육과 겹치지 않는 창. 승인자·이력 일치|
|복원·연락 / 공급 운영강사|관리자 1명. 복원 및 연락 인계|30분×1회|30분/30분|유지보수 인계 전. 복원 결과·연락 순서 재현|

위 편성의 순수 강의는 **7시간 15분**, 수강은 **12시간 15분·인**이다. 최소 잔류가 4명으로 바뀌면 현장 두 과정은 각 5회로 늘고 현장 과정 강의는 (45+60)×5=525분이다. 보강은 예컨대 미통과자 1명당 30분, 강사·대리의 가용 창에서 별도 잡고 재시연 날짜를 남긴다. 품질 2명이 동시에 이탈할 수 없으면 90분×2회로 다시 계산한다. 강사도 최소 잔류 인력에 포함되어 있으면 강사 부재를 차감해 재편성한다.

## 9~15. 운영, 협약, 안전, 증빙

|결정|판단을 바꾸는 자료·옵션|작성할 결과와 승인 전제|
|---|---|---|
|⑨ 보증·유지보수|보증과 유상운영을 장비·SW·모델별로 나눈다. 근무시간 원격지원, 교대 외 긴급출동을 장애 영향·출장비·예산으로 비교한다. 협상 예로 생산중단 접수 후 근무시간 내 1시간 안에 회신, 저위험 조회 오류는 다음 근무일 회신을 제시할 수 있다.|접수 담당→생산 수동 전환→회신→우회→복구·이력 대사→재개 담당을 표시한다. 장애 등급·보증 기산점·기간·부품/출장비·운영시간·예외·SLA와 서명 상태를 적는다. 제안 시간을 계약상 복구 보증으로 승격하지 않는다.|
|⑩ 중단·기성·권리|도입사·공급사·쌍방·불가항력별 중단 통지, 기성 인정 범위, 장비 인도/회수·SW 라이선스·데이터 반출·키 반납을 비교한다. 예시 계약가 1,000만원, 순수 인정기성 40%, 선지급 500만원이면 인정액 400만원, 정산 차액 −100만원으로 반환 검토이다. 선지급 300만원이면 추가지급 검토 100만원이다.|계약 조항·검수 성과 단위·귀책 인정·세액·실비를 반영해 재산정한다. 개발 진척률을 승인된 기성률이나 지급의무로 쓰지 않는다. 인계받을 버전·파일목록·권리 범위·말소 확인 담당을 단계별로 적는다.|
|⑪ 제도 사업교육|6장의 사용자 조작 실습과 별개로 도입/공급의 과정·예정 대상·등록 창·대리·확인 서류·지연 시 대체 회차를 쓴다. 회차 자료가 없으면 예를 들어 ‘착수 후 첫 공지 때 대표·PM 자격 대조→허용된 일정 선택’을 제안한다.|공고 과정 목록·인정기간·정원·명부가 도착하면 대상·날짜 순으로 갱신한다. 접수·출석·수료를 분리하고 양사 수료증별로 추적한다.|
|⑫ 고용|도입·공급사를 구분해 기준일 현원, 다음 연도별 유지/채용/이탈·직무전환을 적는다. 예시 기준 8명, 이탈 1명·신규 2명이면 차기말 9명(순증 1), 내부 전환 2명은 순증에 더하지 않는다.|인사 명부·채용 의사·예산 확인 전은 시나리오로 둔다. 미제공은 공란과 요청 상태로, 승인된 무채용은 0명으로 표기한다. 확대 여부 조건·재확인 시점을 적는다.|
|⑬ 산업안전|설치·시험·운영 위험별로 중단 신호, 접근통제·비상연락/응급지원, 지정 안전책임·현장 승인, 재개 점검, 기록을 구분한다. 교육·점검은 작업 전/변경 시/재개 전 등 사건 기준 일정과 담당을 제시한다.|위험성평가·작업허가·담당자 지정이 없으면 관련 설치를 보류한다. 장소별 비상연락망·구조 요청·대피 집결점은 승인 자료로 채운다. 위험작업 방법은 자격 있는 담당자와 현장 승인 절차를 따른다.|
|⑭ 보안|시설 출입·방문/반출, 입퇴사 권한·교육, 원격 접속·회수, 자료 보존·파기, 복원·예외 승인을 통제별로 쓴다. 생산중단 허용시간과 백업 정책에 따라 현장 복구/격리 복구 안을 비교한다.|통제별 책임·점검주기·적용 상태·테스트·기록 ID를 적는다. 예를 들어 퇴사 처리 후 권한 재조회, 복구 후 원장 대사. 정책·로그·장소 증빙 수신 전은 적용 예정/미확인이다.|
|⑮ 사업계획 최종합의|붙임에 협의 버전·일시·쟁점·결정·양측 권한자/대리·서명 상태를 두고, 조건 변경 시 재승인할 금액·수량·검수 항목을 정한다. 이견은 원안/대안/결정권자/다음 협의 시점으로 기록한다.|한쪽 서명·타 버전 회의록이면 해당 사실만 표시하고 양측 최종합의는 보류한다. 계획합의서, 발주·계약, 구축 후 인수서를 별개로 관리한다.|

## 검토에서 남기는 변화

각 행에 ‘이전 결정·이번 입력과 위치·현재 채택/보류·범위·판단 주체·반영 위치·다음 조건’을 작성한다. 수치가 바뀌면 BOM, 비용, 검수, 인력 시간, 해당 붙임을 함께 갱신한다. 미수령 건수 감소와 실물 확인 건수는 별도로 집계한다. 작성자가 만든 연습용 도면·견적·회의록은 합성 태그를 유지한다. 새 합성 자료로 A/B 중 하나를 모의 채택할 수 있지만 실제 발주·실명 투입·고용·교육 이수·안전 이행·서명의 근거가 되지 않는다. 실제 자료의 권한·대상·기간·버전 충돌은 각 후보와 양측 상태를 유지하고 결정권자의 확인까지 보류한다.
